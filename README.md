# Sales & Revenue Performance Analytics

**Stack:** SQL + Power BI + Excel

Portfolio-grade business analytics project built on **30,000 synthetic 2025 order records**.

## Includes
- 30K-row sales dataset
- SQL schema + 10 business analysis queries
- Power BI DAX measures + 4-page dashboard build guide
- Excel workbook with raw data and analysis sheets
- 4-page professional dashboard PDF
- Data dictionary
- Resume bullets
- Interview preparation
- Business recommendations

## Dashboard
1. Executive Overview
2. Sales Drivers & Market Performance
3. Product, Pricing & Profitability
4. Business Action Plan

**Important:** The dataset is synthetic and is not Snabbit/internal company data.
