# Interview Prep

**30-second answer:** “I built a synthetic sales analytics project using SQL, Power BI and Excel. I analyzed 30,000 orders to understand revenue, profit, AOV, category, city, channel and segment performance. I also studied discounts versus profitability and converted the analysis into a four-page management dashboard.”

**Prepare:** SQL GROUP BY, CASE, JOINs, CTEs, window functions, date functions, aggregates and NULL handling. Power BI data modeling, star schema, relationships, DAX measures, filter context, slicers and dashboard storytelling.

**Likely questions:** Why SQL? Which KPIs? How is AOV calculated? How did you analyze discounts? Why can high revenue be misleading? What would you improve next? Is the data real?

**Answer to data-source question:** “No. It is synthetic portfolio data created to demonstrate analytics skills.”
